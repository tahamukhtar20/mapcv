## Install

<Tabs syncKey="installer">
  <TabItem label="pip">
    ```bash
    python -m pip install mapcv
    ```
  </TabItem>
  <TabItem label="uv">
    ```bash
    uv pip install mapcv
    # or, in a uv project:
    uv add mapcv
    ```
  </TabItem>
  <TabItem label="pipx (CLI only)">
    ```bash
    pipx install mapcv
    ```
  </TabItem>
</Tabs>

mapcv needs **Python 3.10 or newer** (3.10 – 3.14 are tested). One pre-built wheel per platform covers every supported Python version:

| Platform | Wheel |
| --- | --- |
| Linux x86-64 and aarch64 (glibc, e.g. Ubuntu, Debian, Docker on Apple Silicon) | yes |
| Linux x86-64 and aarch64 (musl, e.g. Alpine) | yes |
| macOS (Intel and Apple Silicon) | yes |
| Windows x86-64 | yes |
| Other (for example Windows on ARM) | builds from the source distribution; needs a [Rust toolchain](https://rustup.rs/) |

The base install is small: Pillow, NumPy, Shapely, Pydantic, Typer, Rich, PyYAML, pyproj (its wheel bundles PROJ, so there is nothing else to install) and pyshp (a pure-Python Shapefile reader, so Shapefile labels work out of the box; GeoPackage needs only the standard library). There is no GDAL or rasterio dependency. XYZ tiles and GeoTIFF/COG files (local, `https://` or public `s3://`) work with the base install alone; only Sentinel-2 needs an extra.

## Optional extras

| Extra | Install | Adds | Python |
| --- | --- | --- | --- |
| `zarr` | `pip install "mapcv[zarr]"` | Sentinel-2 L2A EOPF Zarr input: xarray-eopf, xarray, Dask, zarr 2, numba (≥ 0.68), pyproj, s3fs | 3.10 – 3.13 |
| `parquet` | `pip install "mapcv[parquet]"` | GeoParquet label files (`.parquet`, `.geoparquet`): pyarrow | 3.10 – 3.14 |
| `export` | `pip install "mapcv[export]"` | `mapcv export --format hf-parquet` (Hugging Face Parquet): pyarrow | 3.10 – 3.14 |
| `mcp` | `pip install "mapcv[mcp]"` | The MCP server for AI agents (`mapcv mcp`): the official [MCP Python SDK](https://github.com/modelcontextprotocol/python-sdk) and its dependencies. See [Use mapcv with AI agents](/mapcv/guides/use-with-ai-agents/) | 3.10 – 3.14 |

<Aside type="caution" title="Sentinel-2 and Python 3.14">
The `zarr` extra depends on zarr 2, whose `numcodecs` dependency has no Python 3.14 wheels. On Python 3.14, `pip install "mapcv[zarr]"` succeeds but installs **none** of the extra packages; a Sentinel-2 run then stops with a message explaining that Sentinel-2 support needs Python 3.10–3.13. Use a Python 3.13 environment for Sentinel-2.
</Aside>

## Verify

```console
$ mapcv --version
mapcv 0.2.0
```

`mapcv --help` (or `mapcv -h`) lists the commands, grouped in the order you use them: **1. Build a dataset** (`init`, `plan`, `generate`), **2. Use a dataset** (`info`, `split`) and **3. Utilities** (`validate`). If the shell says `command not found`, activate the environment you installed into, or run `python -m pip show mapcv` to see where it went.

## Shell completion

mapcv's CLI is built with Typer, which can install tab completion for bash, zsh, fish and PowerShell:

```bash
mapcv --install-completion   # install for the current shell, then restart it
mapcv --show-completion      # print the script, to install it yourself
```

## Build from source

Use this for development or on platforms without a wheel.

<Steps>

1. Install [Rust](https://rustup.rs/) (stable) and Python 3.10+.

2. Clone the repository:

   ```bash
   git clone https://github.com/tahamukhtar20/mapcv
   cd mapcv
   ```

3. Build and install into the active environment. `--release` turns on Rust optimisations; debug builds are much slower.

   ```bash
   python -m pip install maturin
   maturin develop --release
   ```

   Contributors use `uv sync --extra dev && uv run maturin develop` instead; see [Contributing](/mapcv/project/contributing/).

</Steps>
