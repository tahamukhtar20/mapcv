---
title: Provider terms and imagery licensing
description: Responsibilities when using imagery with mapcv.
---

mapcv processes imagery; it does not provide imagery or grant permission to download, cache, redistribute, or train models on provider data.

Before use, review the provider's current license, attribution requirements, automated-access rules, quotas, and restrictions on derived datasets and trained models. Use an official endpoint and only credentials you are authorized to use.

Keep API keys and signed URLs out of YAML, logs, manifests, examples, and source control. Built-in XYZ names are conveniences rather than endorsements or license guarantees. Custom XYZ templates are supported, but are not stored in manifest v2.

EOPF 0.2 input supports local products and anonymously public HTTP(S) or S3 locations. Usernames, passwords, query strings, fragments, and arbitrary credential dictionaries are rejected. Private-store authentication is not part of this release.
