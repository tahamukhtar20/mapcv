## Built for the dataset step, and only that

<CardGrid>
  <Card title="No GDAL, Rust core" icon="seti:rust">
    Tile math, fetching, rasterizing, sampling and patch encoding run in Rust. One wheel per
    platform covers Python 3.10 and newer. `pip install` and go.
  </Card>
  <Card title="Leakage-safe splits" icon="approve-check">
    The default `spatial` split keeps whole blocks of the map in one split and drops train/val
    patches that overlap a test patch, so scores aren't inflated by shared pixels.
  </Card>
  <Card title="Aerial tiles or Sentinel-2" icon="seti:image">
    Esri and CartoDB XYZ presets or your own tile URL, or one Sentinel-2 L2A EOPF Zarr product
    with band selection at 10, 20 or 60 m.
  </Card>
  <Card title="Large regions, resumable" icon="puzzle">
    `mapcv plan` estimates tiles, disk and memory first. Generation runs in chunks, saves the
    manifest after each one, and picks up where it stopped.
  </Card>
  <Card title="ML-ready output" icon="seti:pipeline">
    Image and mask patches with identical names, stable class IDs, a JSON manifest and plain-text
    split lists. Load them with NumPy, PyTorch or anything else.
  </Card>
  <Card title="Honest about imagery rights" icon="information">
    mapcv ships no presets for servers that forbid bulk downloads and keeps API keys out of
    manifests. Licensing stays your call, and the docs tell you what to check.
  </Card>
</CardGrid>

## Where mapcv fits

mapcv does one job: it writes a static, reproducible segmentation dataset from map imagery and polygons.

- **[TorchGeo](https://github.com/microsoft/torchgeo)** samples patches on the fly from GeoTIFFs inside PyTorch and ships many benchmark datasets. Pick it if your imagery already lives in rasters and you train in PyTorch.
- **[Raster Vision](https://github.com/azavea/raster-vision)** covers the full workflow from data to trained model and prediction. Pick it if you want one framework end to end.
- **GDAL/rasterio scripts** handle every raster format and projection. mapcv supports a deliberately narrow set of inputs (XYZ tiles, one Sentinel-2 EOPF product per run) so it can install without GDAL.

The tools combine well: a mapcv dataset is plain files, so you can train it with any library.
