 Usage: mapcv verify [OPTIONS] {staging_dir}

 Check that every file is present and intact (and SHA256SUMS, when there is one).

╭─ Arguments ──────────────────────────────────────────────────────────────────────────╮
│ *    staging_dir      <path>  Dataset directory containing manifest.json. [required] │
╰──────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────╮
│ --deep                       Also decode every image and check its shape.            │
│ --write-checksums            Write SHA256SUMS after a successful check.              │
│ --help             -h        Show this message and exit.                             │
╰──────────────────────────────────────────────────────────────────────────────────────╯

 Examples:

 mapcv verify dataset/

 mapcv verify dataset/ --deep --write-checksums
