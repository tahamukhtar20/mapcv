 Usage: mapcv init [OPTIONS] [OUTPUT]

 Create a config: answer a few questions, or start from a template.

╭─ Arguments ──────────────────────────────────────────────────────────────────────────╮
│   OUTPUT      <path>  Where to write the config. [default: mapcv.yaml]               │
╰──────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────╮
│ --template     -t                      <xyz|sentinel2|geotif  Write a ready-made     │
│                                        f|earth-engine|detect  example instead of     │
│                                        ion|instance|classifi  asking.                │
│                                        cation|change|regress                         │
│                                        ion>                                          │
│ --interactive      --no-interactive                           Ask questions          │
│                                                               (default: when run in  │
│                                                               a terminal without     │
│                                                               --template).           │
│ --force        -f                                             Overwrite an existing  │
│                                                               file.                  │
│ --stdout                                                      Print the template     │
│                                                               instead of writing.    │
│ --help         -h                                             Show this message and  │
│                                                               exit.                  │
╰──────────────────────────────────────────────────────────────────────────────────────╯

 Examples:

 mapcv init                         guided, writes mapcv.yaml

 mapcv init --template xyz --stdout   print a template

 mapcv init my.yaml --template sentinel2   a ready-made example

 mapcv init gee.yaml --template earth-engine   cloud-free Sentinel-2 from Earth Engine

 mapcv init boxes.yaml --template detection   boxes for COCO and YOLO

 mapcv init masks.yaml --template instance   a mask per object (COCO RLE)

 mapcv init tiles.yaml --template classification   a label per patch (CSV)

 mapcv init pairs.yaml --template change   before/after pairs and change masks

 mapcv init heights.yaml --template regression   float targets from a raster
