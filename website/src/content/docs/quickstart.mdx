In five minutes you will build a small, labeled dataset of building footprints over Amsterdam's Eastern Docklands: Esri aerial imagery at about 0.36 m per pixel, OpenStreetMap building polygons as labels, cut into 256 × 256 patches with a leakage-safe train/val/test split.

You need Python 3.10+ and an internet connection. Everything below is real output from `mapcv` 0.2.0.

<Steps>

1. ### Install

   ```bash
   pip install mapcv
   ```

   Check it worked with `mapcv --version`. More options: [Installation](/mapcv/installation/).

2. ### Get some labels

   Make a working folder and download the example building outlines (967 OpenStreetMap polygons, © OpenStreetMap contributors, ODbL):

   ```bash
   mkdir buildings && cd buildings
   curl -LO https://raw.githubusercontent.com/tahamukhtar20/mapcv/main/examples/quickstart/buildings.geojson
   ```

   Any polygon GeoJSON or KML in longitude/latitude, or a GeoPackage, Shapefile or GeoParquet file in any CRS, works the same way; see [Prepare labels](/mapcv/guides/prepare-labels/).

3. ### Write a config with `mapcv init`

   `mapcv init` asks four questions and writes `mapcv.yaml`. Type the answers shown after the prompts below; press <kbd>Enter</kbd> for the others to accept the default:

   ```console
   $ mapcv init
   ╭─ mapcv init ─────────────────────────────────────────────────────────────────────────╮
   │ Answer a few questions to get a working config. Press Enter to accept a default.     │
   ╰──────────────────────────────────────────────────────────────────────────────────────╯

   1/4 Imagery
     esri       Esri World Imagery — sub-metre RGB (check Esri's terms)
     sentinel2  Sentinel-2 L2A — open 10 m multispectral (EOPF Zarr)
     custom     your own XYZ tile URL
   Imagery [esri/sentinel2/custom] (esri):

   2/4 Area
   Area: a bounding box west,south,east,north or a .geojson/.kml file: 4.9375,52.3725,4.9515,52.3780
     zoom    pixel size
       15    2.92 m
       16    1.46 m
       17    0.73 m
       18    0.36 m
       19    0.18 m
   Zoom (17): 18

   3/4 Labels
   Label file (.geojson/.kml; blank for an image-only dataset): buildings.geojson
     field       example values
     class       building
     building    house, apartments, houseboat, yes, retail
   Which field holds the class? (blank = every polygon is class 1) (): class

   4/4 Patches and output
   Patch size in pixels (256):
   Output folder (./dataset):
   Split into train/val/test (spatial, no leakage)? [y/n] (y):

   ✓ Wrote mapcv.yaml

   Next
     1. See what it will cost:  mapcv plan mapcv.yaml
     2. Build the dataset:      mapcv generate mapcv.yaml
   ```

   The area can also be a `.geojson` or `.kml` file: mapcv then uses the extent of its polygons and offers the same file as labels. The result is a short, commented YAML file you can edit and commit:

   ```yaml title="mapcv.yaml"
   region:
     west: 4.937500
     south: 52.372500
     east: 4.951500
     north: 52.378000

   imagery:
     type: xyz
     zoom: 18
     source: esri_satellite
     max_connections: 4         # keep requests modest

   labels:
     path: 'buildings.geojson'
     label_field: class

   sampler:
     patch_size: 256
     stride: 0                  # 0 = no overlap
     mode: grid
     edge_strategy: pad

   writer:
     staging_dir: './dataset'
     image_format: png

   split:
     strategy: spatial
     test_ratio: 0.20
     val_ratio: 0.10
   ```

   Relative paths are resolved against the folder that contains `mapcv.yaml`, so the config works from any directory.

   <Aside type="tip" title="No terminal prompts?">
   In scripts and CI, start from a template instead: `mapcv init --template xyz` writes `mapcv.yaml` (or pass another path), `--template sentinel2` gives a Sentinel-2 example, and `--stdout` prints the template instead of writing it. Edit the region and label path afterwards.
   </Aside>

4. ### Check the cost with `mapcv plan`

   `plan` reads the labels and does the tile math, but downloads nothing:

   ```console
   $ mapcv plan mapcv.yaml
   ╭─ Plan for mapcv.yaml ────────────────────────────────────────────────────────────────╮
   │ Region   4.9375, 52.3725 → 4.9515, 52.378  (≈ 1.0 × 0.6 km)                          │
   │ Imagery  esri_satellite · zoom 18 (≈ 0.36 m/px)                                      │
   │ Raster   2,816 × 1,792 px · 77 tiles (≈ 1.9 MB to download)                          │
   │ Labels   buildings.geojson · 967 polygon(s) · classes: building → 1                  │
   │ Patches  ≈ 77 × 256 px (grid, stride 256)                                            │
   │ Output   dataset · png (≈ 8.6 MB)                                                    │
   │ Split    spatial · test 0.2 · val 0.1                                                │
   │ Memory   ≈ 28.8 MB per chunk                                                         │
   ╰──────────────────────────────────────────────────────────────────────────────────────╯
   Imagery terms are your responsibility: check the provider's license, attribution and
   rate limits (https://github.com/tahamukhtar20/mapcv/blob/main/PROVIDERS.md).

   Looks right? Build it with mapcv generate mapcv.yaml
   ```

   Warnings appear under the panel, for example when label features are skipped or no polygon falls inside the region. Sizes are estimates.

5. ### Build it with `mapcv generate`

   ```console
   $ mapcv generate mapcv.yaml
   ╭─ Plan for mapcv.yaml ─────────────────── (same panel as above) ──────────────────────╮
   ╰──────────────────────────────────────────────────────────────────────────────────────╯
     Reading imagery and writing patches ━━━━━━━━━━━━━━━ 2/2 chunks • 0:00:21 • eta 0:00:00
   ╭─ Dataset ready ──────────────────────────────────────────────────────────────────────╮
   │ Patches  77                                                                          │
   │ Shape    256×256×3 uint8                                                             │
   │ Tiles    77 fetched · 0 failed                                                       │
   │ Splits   train 52 (68%) · val 8 (10%) · test 17 (22%)                                │
   │ Time     21s                                                                         │
   │ Files    dataset/ (Images/, Masks/, manifest.json, splits/)                          │
   ╰──────────────────────────────────────────────────────────────────────────────────────╯
     class         id    pixels
     background     0     81.0%
     building       1     19.0%

   Next
     • Inspect it:      mapcv info dataset
     • Re-split it:     mapcv split dataset --strategy spatial
     • Band stats:      mapcv stats dataset
     • Train on it:     https://tahamukhtar20.github.io/mapcv/guides/use-your-dataset/
   ```

   If the run is interrupted, run the same command again: finished chunks are kept and it resumes. Jobs over 20,000 tiles or 5 GB ask for confirmation first; pass `--yes` to skip the prompt.

6. ### Inspect it with `mapcv info`

   ```console

   ╭─ dataset ────────────────────────────────────────────────────────────────────────────╮
   ```

</Steps>

## What you built

<FileTree>
- buildings/
  - mapcv.yaml
  - buildings.geojson
  - dataset/
    - Images/ 77 RGB PNG patches, 256 × 256
      - patch_0000000.png
      - …
    - Masks/ 77 single-channel PNGs: 0 = background, 1 = building
      - patch_0000000.png
      - …
    - manifest.json
    - splits/
      - train.txt
      - val.txt
      - test.txt
      - split.json settings and counts of this split
      - 10/
      - 20/
      - 30/ labeled/unlabeled subsets of train
</FileTree>

Load a pair to check that the mask lines up:

```python
import numpy as np
from PIL import Image

name = open("dataset/splits/train.txt").read().split()[0]
image = np.asarray(Image.open(f"dataset/Images/{name}"))   # (256, 256, 3) uint8
mask = np.asarray(Image.open(f"dataset/Masks/{name}"))     # (256, 256) uint8, values 0/1
print(name, image.shape, mask.shape, np.unique(mask))
```

<Aside>
Your patch counts and split sizes can differ slightly if the example labels are refreshed. The download time depends on the tile server.
</Aside>
