If mapcv helped you build a dataset for published work, please cite the software and say which version you used (`mapcv --version`). The DOI [10.5281/zenodo.23149438](https://doi.org/10.5281/zenodo.23149438) covers every release and always resolves to the latest one; use it so that all citations count toward one record. The repository's [`CITATION.cff`](https://github.com/tahamukhtar20/mapcv/blob/main/CITATION.cff) is what GitHub's "Cite this repository" button uses.

<Tabs>
  <TabItem label="BibTeX">
    ```bibtex
    @software{mukhtar_mapcv,
      author  = {Mukhtar, Muhammad Taha},
      title   = {mapcv: computer-vision datasets from map imagery and geospatial labels},
      version = {0.2.0},
      year    = {2026},
      doi     = {10.5281/zenodo.23149438},
      url     = {https://github.com/tahamukhtar20/mapcv},
      license = {MIT}
    }
    ```
  </TabItem>

Adjust `version` and `year` to the release you used. If you need to point at one exact release, its own DOI is listed on the [Zenodo page](https://doi.org/10.5281/zenodo.23149438) (for 0.2.0: 10.5281/zenodo.23149439).

## Cite your data, too

A mapcv dataset is made of other people's data. Credit each source as its terms require, for example:

| Source | Typical credit |
| --- | --- |
| Copernicus Sentinel-2 | "Contains modified Copernicus Sentinel data [year]" |
| OpenStreetMap labels | "© OpenStreetMap contributors", data under the ODbL |
| Esri World Imagery and other XYZ providers | As required by the provider's terms; see [Providers & licensing](/mapcv/project/providers/) |

<Aside>
In a methods section, also state the split strategy, block size and seed from your config, so others can reproduce your train/val/test partition from the manifest with `mapcv split`. mapcv records them in `splits/split.json`.
</Aside>
