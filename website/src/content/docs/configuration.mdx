Use `mapcv init` to scaffold an annotated XYZ configuration. A config selects exactly one imagery type.

## `region`

The area of interest in WGS-84 longitude/latitude.

| Field | Type | Description |
|---|---|---|
| `west` | float | Western longitude |
| `south` | float | Southern latitude |
| `east` | float | Eastern longitude |
| `north` | float | Northern latitude |

`west` must be below `east`, and `south` below `north`.

## `imagery`

### XYZ tiles

```yaml
imagery:
  type: xyz
  zoom: 17
  source: osm
  strip_rows: 4
  max_connections: 2        # keep low for OSM; see its tile usage policy
  policy: lenient
  max_failed_ratio: 0.05
```

Exactly one of `source` or `url_template` is required.

| Field | Type | Default | Description |
|---|---|---|---|
| `type` | `xyz` | required | Selects the XYZ adapter |
| `zoom` | int | required | XYZ zoom level, 1–22 |
| `source` | str | — | Built-in source name |
| `url_template` | str | — | Custom URL with `{z}`, `{x}`, and `{y}` placeholders |
| `strip_rows` | int | `4` | Tile rows per processing chunk |
| `max_connections` | int | `16` | Parallel tile fetches |
| `policy` | str | `lenient` | `strict`, `lenient`, or `ignore` |
| `max_failed_ratio` | float | `0.05` | Global failure threshold for `lenient` |

Built-in sources are `osm`, `esri_satellite`, `esri_topo`, `esri_street`, `cartodb_positron`, and `cartodb_dark_matter`.

<Aside type="caution">
XYZ sources must return 256 × 256 pixel tiles. You are responsible for provider terms, licensing, attribution, quotas, and authorized access. See [Provider guidance](/mapcv/providers/).
</Aside>

### EOPF Sentinel-2 L2A Zarr

Install the optional backend with `pip install "mapcv[zarr]"`.

```yaml
imagery:
  type: eopf_zarr
  path: /data/S2_L2A_PRODUCT.zarr
  resolution: 10
  bands: [b01, b02, b03, b04, b05, b06, b07, b08, b8a, b09, b11, b12]
  chunk_rows: 1024
```

| Field | Type | Default | Description |
|---|---|---|---|
| `type` | `eopf_zarr` | required | Selects the EOPF adapter |
| `path` | str | required | Local product or anonymous public HTTP(S)/S3 URL |
| `resolution` | int | `10` | Harmonized resolution: 10, 20, or 60 metres |
| `bands` | list[str] | L2A reflectance set | Variables to load, in output order |
| `chunk_rows` | int | `1024` | Raster rows per processing chunk |

The backend preserves the product's native projected CRS. URLs cannot contain credentials, query strings, or fragments. One product is supported per run.

## `labels` (optional)

| Field | Type | Default | Description |
|---|---|---|---|
| `path` | str | required | `.kml` or `.geojson` annotation file |
| `label_field` | str | `null` | Property used as the class label; `null` assigns class 1 |
| `all_touched` | bool | `false` | Include every pixel touched by polygon boundaries |

Labels are interpreted as WGS-84 and transformed into the imagery CRS before rasterization.

## `sampler`

| Field | Type | Default | Description |
|---|---|---|---|
| `patch_size` | int | required | Square patch side in pixels |
| `stride` | int | `0` | Anchor step; `0` uses `patch_size` |
| `mode` | str | `grid` | `grid` or `random` |
| `edge_strategy` | str | `pad` | `pad`, `drop`, or `shift` |
| `pad_mode` | str | `zero` | `zero` or `reflect` |
| `max_empty_ratio` | float | `1.0` | Drop patches above this NoData fraction |
| `min_label_ratio` | float | `0.0` | Drop patches below this labeled fraction |
| `random_count` | int | `100` | Random anchor count |
| `random_seed` | int | `42` | Reproducible random seed |

For EOPF imagery, decoded NoData and NaN pixels determine emptiness. Numeric zero remains a valid reflectance value.

## `writer`

| Field | Type | Default | Description |
|---|---|---|---|
| `staging_dir` | str | required | Dataset output directory |
| `image_format` | str | `png` | `png` or `jpg` for XYZ; required `npy` for EOPF |
| `jpg_quality` | int | `95` | JPEG quality from 1–100 |

NPY image patches have `(bands, height, width)` shape and decoded `float32` values.

## `split` (optional)

| Field | Type | Default | Description |
|---|---|---|---|
| `test_ratio` | float | `0.20` | Fraction reserved for testing |
| `val_ratio` | float | `0.10` | Fraction of the remaining pool used for validation |
| `labeled_ratios` | list[float] | `[0.10, 0.20, 0.30]` | Semi-supervised labeled subsets |
| `seed` | int | `42` | Split seed |
| `strategy` | str | `stratified` | `stratified` or `random` |
| `sample_limit` | int | — | Optional cap before splitting |

## Legacy 0.1 configuration

`region.zoom` plus `tiles` is accepted with a deprecation warning until 0.3.0. See the [0.2 migration guide](/mapcv/migration/).
