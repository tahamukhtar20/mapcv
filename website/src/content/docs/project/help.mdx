---
title: Getting help
description: Where to ask questions, report bugs and report security problems for mapcv.
---

Start with the [FAQ](/mapcv/project/faq/) and, if a command fails, `mapcv doctor`, which checks your install and network. If that does not answer it:

- **Questions and ideas.** Ask in [GitHub Discussions](https://github.com/tahamukhtar20/mapcv/discussions). It is also the place to share a dataset you built or to float an idea before opening an issue.
- **Bugs and feature requests.** Open an [issue](https://github.com/tahamukhtar20/mapcv/issues/new/choose) and fill in the template. For a bug, include the output of `mapcv --version`, your `mapcv.yaml` (remove any credentials from `url_template`) and the command you ran.
- **Security problems.** Report them privately through [GitHub's private vulnerability reporting](https://github.com/tahamukhtar20/mapcv/security/advisories/new), not in a public issue. The [security policy](https://github.com/tahamukhtar20/mapcv/blob/main/SECURITY.md) lists what is in scope and what to expect.

To contribute a fix or a feature, see [Contributing](/mapcv/project/contributing/).
