**mapcv** turns a bounding box and optional polygon labels into a ready-to-train satellite imagery dataset for semantic segmentation. You give it a geographic region, an XYZ or EOPF Sentinel-2 L2A source, and optionally a KML or GeoJSON annotation file. It reads the imagery, aligns and rasterizes labels, extracts fixed-size patches, and writes everything to disk.

To keep installation light, the core XYZ pipeline does not depend on GDAL. The optional `mapcv[zarr]` extra for EOPF Sentinel-2 pulls in rasterio, which ships its own GDAL wheels. Tile stitching, rasterization, and patch sampling are powered by Rust, while the Python layer handles orchestration, configuration, and access via the CLI or API.

---

## Key concepts

- **Bounding box**: The target area in WGS-84 (longitude/latitude). mapcv expands these coordinates outward to align with the nearest tile grid so no downloaded tiles are partially cut off.
- **Resolution**: XYZ uses a zoom level. EOPF Sentinel-2 uses a harmonized 10, 20, or 60 metre grid while preserving the product's native projected CRS.
- **Chunks**: Sampling anchors are generated globally, then imagery is read in row chunks with a patch halo so seam patches are neither lost nor duplicated.
- **Patches**: Fixed-size square crops extracted from the stitched image. Each patch has a matching mask file of the same name.
- **Class IDs**: Mask pixels are `0` (background) or `1..255` (class). When `label_field` is `null`, all polygons get `class_id = 1`. When a field name is given, IDs are assigned by encounter order starting at 1.

---

## When to use mapcv

- You have polygon annotations (KML or GeoJSON) and want pixel-level segmentation masks.
- You want image-only patches (unlabeled) — just omit the `labels` section.
- You need a reproducible pipeline that goes from a config file to a ready-to-train dataset in one command.
- You need selected Sentinel-2 L2A reflectance bands as bands-first `float32` NPY patches.

## Quick start guide

Get up and running with `mapcv` and generate your first dataset in three simple steps.

### 1. Install mapcv

Install the latest version of mapcv using pip.

```bash
pip install mapcv
```

### 2. Configure your dataset

Generate a template configuration file and customize it to fit your needs:
```bash
mapcv init my_dataset.yaml
```
> **Note**: For details on all available settings, check out the [Configuration Reference](/mapcv/configuration) page.

### 3. Generate the dataset

Once your configuration file is ready, run the following command to start the generation process:

```bash
mapcv generate my_dataset.yaml
```

That's it! Your generated dataset will be saved to the output directory you specified in your configuration file.
