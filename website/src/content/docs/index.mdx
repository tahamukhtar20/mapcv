## What is mapcv?

**mapcv** turns a bounding box and optional polygon labels into a ready-to-train image segmentation dataset.
It reads XYZ map tiles or one EOPF Sentinel-2 L2A Zarr product, aligns KML or GeoJSON annotations, extracts fixed-size patches, and writes them to disk. Base XYZ support does not need GDAL; EOPF support is an optional install that brings in rasterio.
## Features

<CardGrid>
  <Card title="Rust-accelerated core" icon="rocket">
    Tile stitching, polygon rasterization, and patch sampling all run in compiled Rust via PyO3, which is orders of magnitude faster than other implementations.
  </Card>
  <Card title="Many tile sources" icon="external">
    Built-in support for Esri and CartoDB endpoints, plus authorized custom XYZ URL templates.
  </Card>
  <Card title="Multispectral EOPF Zarr" icon="database">
    Lazy Sentinel-2 L2A band selection, resolution harmonization, native projected CRS, and bands-first float32 NPY output.
  </Card>
  <Card title="KML & GeoJSON labels" icon="pencil">
    Parse polygon annotations directly from KML or GeoJSON files. Multiclass labels via a configurable field name. Automatic WGS-84 to imagery-CRS projection.
  </Card>
  <Card title="Flexible patch sampling" icon="setting">
    Grid or random sampling with configurable stride, edge strategies (pad / drop / shift), and empty-patch filtering.
  </Card>
  <Card title="Train / val / test splits" icon="list-format">
    Stratified or random dataset splitting from the JSON manifest. Configurable labeled-data fractions for semi-supervised workflows.
  </Card>
  <Card title="Simple CLI" icon="laptop">
    Run the full pipeline with `mapcv generate config.yaml`. One command, one config file, ready-to-train output.
  </Card>
</CardGrid>
