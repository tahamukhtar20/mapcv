## Labeled XYZ dataset

```yaml
region:
  west: 4.883
  south: 52.371
  east: 4.896
  north: 52.378

imagery:
  type: xyz
  zoom: 17
  source: osm
  strip_rows: 4
  policy: lenient

labels:
  path: buildings.kml
  label_field: null
  all_touched: false

sampler:
  patch_size: 256
  stride: 0
  edge_strategy: drop

writer:
  staging_dir: ./output
  image_format: png
```

## EOPF multispectral dataset

```yaml
region:
  west: 10.0
  south: 45.0
  east: 10.2
  north: 45.2

imagery:
  type: eopf_zarr
  path: /data/S2_L2A_PRODUCT.zarr
  resolution: 10
  bands: [b08, b04, b03]
  chunk_rows: 1024

labels:
  path: landuse.geojson
  label_field: class

sampler:
  patch_size: 128
  stride: 64
  max_empty_ratio: 0.25

writer:
  staging_dir: ./sentinel_dataset
  image_format: npy
```

The output array order is exactly `b08`, `b04`, `b03`, with shape `(3, 128, 128)` and `float32` dtype.

## Unlabeled dataset

Omit `labels`; no `Masks/` directory is created.

```yaml
imagery:
  type: xyz
  zoom: 19
  source: esri_satellite

sampler:
  patch_size: 512
  edge_strategy: shift

writer:
  staging_dir: ./output
  image_format: jpg
  jpg_quality: 90
```

## Custom XYZ source

Use only a URL you are authorized to access. Do not commit keys or signed query strings.

```yaml
imagery:
  type: xyz
  zoom: 16
  url_template: "https://tile.example.com/{z}/{x}/{y}.png"
  max_connections: 8
  policy: lenient
```

## Random sampling and semi-supervised splits

```yaml
sampler:
  patch_size: 256
  mode: random
  random_count: 500
  random_seed: 42

split:
  test_ratio: 0.20
  val_ratio: 0.10
  labeled_ratios: [0.05, 0.10, 0.20]
  strategy: spatial
```
