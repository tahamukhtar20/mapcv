 Usage: mapcv [OPTIONS] COMMAND [ARGS]...

 Turn a region and polygon labels into a ready-to-train segmentation, detection,
 instance or classification dataset.

 Start with mapcv init, check the cost with mapcv plan, then build with mapcv generate.

╭─ Options ────────────────────────────────────────────────────────────────────────────╮
│ --version             -V        Show the mapcv version and exit.                     │
│ --quiet               -q        Hide progress output; still show errors and          │
│                                 summaries.                                           │
│ --install-completion            Install completion for the current shell.            │
│ --show-completion               Show completion for the current shell, to copy it or │
│                                 customize the installation.                          │
│ --help                -h        Show this message and exit.                          │
╰──────────────────────────────────────────────────────────────────────────────────────╯
╭─ 1. Build a dataset ─────────────────────────────────────────────────────────────────╮
│ init      Create a config: answer a few questions, or start from a template.         │
│ plan      Estimate tiles, patches, disk and memory for a config without downloading. │
│ generate  Download imagery, rasterize labels and write patches, masks, manifest and  │
│           splits.                                                                    │
╰──────────────────────────────────────────────────────────────────────────────────────╯
╭─ 2. Use a dataset ───────────────────────────────────────────────────────────────────╮
│ info      Summarize a generated dataset: source, shapes, class balance and splits.   │
│ split     Re-split an existing dataset from its manifest; no images are read.        │
│ stats     Per-band mean and std, class balance and class weights, written to         │
│           stats.json.                                                                │
│ card      Write a dataset card (README.md with Hugging Face metadata) for sharing.   │
│ verify    Check that every file is present and intact (and SHA256SUMS, when there is │
│           one).                                                                      │
│ export    Export a dataset: Hugging Face Parquet, WebDataset shards, Zarr or a       │
│           TerraTorch config.                                                         │
╰──────────────────────────────────────────────────────────────────────────────────────╯
╭─ 3. Utilities ───────────────────────────────────────────────────────────────────────╮
│ validate  Check a config without reading labels or imagery (use plan for estimates). │
│ cache     Show or clear the on-disk cache of downloaded XYZ tiles.                   │
│ mcp       Run an MCP server over stdio so AI agents can build datasets with mapcv.   │
╰──────────────────────────────────────────────────────────────────────────────────────╯
